## Toolchain

The plugin is compiled with Zig's C++ compiler, which the SDK installs from PyPI (`ziglang`), and
with Rust. Their runtime libraries are linked under their own terms. LLVM's libc++ is licensed
Apache-2.0 with the LLVM exception, which needs no notice in binary distributions.

## Fonts and images

The skin names fonts by name ("Titillium Web", "Nexa", "Roboto"). The MPC firmware renders them,
and none are bundled. Every PNG in `plugin/skin/` and `media/` was generated by this project's
scripts (`plugin/skin/make_assets.py`, `scripts/skin_preview.py`) from CHIMERA's anatomy geometry.
The VOICE page's knob and switch images come from the SDK's UI kit (MIT, above). `media/` images
are rendered on a PC with Windows' Segoe UI as a stand-in font. They are documentation only, and
no font file is included.
