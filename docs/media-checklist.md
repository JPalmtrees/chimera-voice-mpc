# Media checklist

The repository has no photos or video from the MPC yet. The images in `media/` are rendered on a
PC from the plugin's real skin files (`scripts/skin_preview.py`) and the real pose atlas, and are
labelled as such. Wherever they are used, add authentic captures in their place:

| File to add | What it should show | Where it is used |
|---|---|---|
| `media/mpc-play-page.jpg` | A photo of the MPC One's screen showing the PLAY page (Lite selected, head visible) | README hero image |
| `media/mpc-live-demo.gif` or a linked video | 10-20 s of singing typed words: the yellow syllable following, the head moving (Animation on) | README, under the hero image |
| `media/mpc-keyboard.jpg` | The keyboard panel open on the MPC | README Features or docs |
| `media/mpc-voice-page.jpg` | The VOICE page with the Quality buttons | optional |

Tips: film the screen straight on, in a dim room, with auto-exposure locked to avoid flicker. A
GIF under about 8 MB displays inline on GitHub. Longer video can go in a release or on a video
site, linked from the README.
